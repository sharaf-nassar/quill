## Quill Session History

- Search past sessions with `quill_search_history`. Never read raw JSONL session logs from the pi session directory directly.
- Route large transient output through the `quill_execute`, `quill_index_context`, `quill_fetch_and_index`, and `quill_search_context` tools.
