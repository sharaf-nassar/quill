Usage over time

Model evidence

See which models actually did the work.

Quill keeps provider-qualified model ids exactly as observed. See what is running now, what it replaced, and the top models by sessions and attributed tokens, with incomplete coverage stated instead of guessed.

Working memory · your agents use it too

Keep bloated context out of the model's window.

Quill gives your agent tools it calls directly — offloading web fetches, command output, and file dumps into a local store and returning only the chunk that matters. A routing layer keeps the bloat out of the transcript, so the model stays focused on its actual work. Claude Code and Codex receive the full tool set through MCP; Pi registers the listed core tools through its managed extension.

Total recall

Every past run, indexed — Claude, Codex, and Pi.

Full-text search across prompts, tool calls, code changes, commands, files, and branches. Find where that fix happened, in any project, in seconds — and your agents can search it too.

Live limits

Know the cap before it cuts the run.

Live quota pressure for Claude and Codex, with utilization, reset countdowns, and severity above every view. Pi contributes session and model evidence but has no quota row. Connect CLI Proxy API to replace direct rows with pooled account pressure.

Behavioral learning

Turn repeated behavior into reviewable rules.

Quill combines tool observations, git history, and recent sessions into evidence-backed candidates. Nothing reaches an agent file until you explicitly promote it, and operator feedback outweighs model opinion.

More agent tools

Memory tools

Keep your agent's memory clean and current.

Quill reviews your CLAUDE.md / AGENTS.md and memory files and proposes merges, updates, and deletions — with a diff, one-click undo, and an optional pass that compresses prose while preserving every code block, path, and number.

Prose compression

Get tighter answers from your agents.

One toggle asks your agent to write its own prose in a compressed style — preserving code, paths, commands, and numbers exactly. Shorter answers, same substance.

Provider control

One place to manage every connection.

Enable Claude Code, Codex, or Pi only after reviewing the local files Quill installs. Choose the provider behind the tray indicator and connect pooled Claude or Codex accounts through CLI Proxy API.
